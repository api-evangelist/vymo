# Vymo

> Vymo is a sales-engagement and distribution-management platform for financial institutions — banks, insurers, and asset managers — helping field sales and collections teams manage leads, allocate and prioritize activities, and capture engagement in a mobile-first app. It layers AI-driven nudges, activity capture, and analytics on top of CRM and core systems. Headquartered in Sunnyvale, California; backed by Emergence Capital.

## API status

Vymo operates a platform API, but it is not public. As of 2026-08-13:

- The API reference is hosted on a **private Read the Docs Business** site at
  https://docs.getvymo.com/ — it returns "Log in to view this documentation" and redirects
  to app.readthedocs.com/accounts/login/. An active tenant or signed agreement is required.
- The application/API host https://app.lms.getvymo.com answers every path with
  `{"authentication_error":"unauthorized"}`.
- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, MCP server, A2A agent card, Postman
  collection or JSON Schema is published at any Vymo-controlled host.
- Vymo publishes no API client library or SDK in npm, PyPI, RubyGems, crates.io, NuGet,
  Maven Central or pkg.go.dev.

Integrations are delivered through enterprise/partner engagements rather than self-serve
onboarding. Note that third-party API portals (for example HDFC Bank's
`Vymo_Push_Lead` endpoint) publish their own interfaces *into* Vymo — those are the
partner's contracts on the partner's host, not Vymo-published APIs.
